Privacy Policy

Last updated: September 15, 2026

1. Overview

This Privacy Policy explains how the Spanish Virtual League Discord Bot ("the Bot", "we", "us", or "our") handles information when you use or interact with the Bot on Discord.

2. Information the Bot Accesses

When a user interacts with the Bot, Discord may provide information necessary for the requested command to work. Depending on the interaction, this can include:

  • Discord user ID, username, and display name
  • Discord server (guild) ID
  • Discord channel ID
  • Command input supplied by the user

3. How Information Is Used

Information available to the Bot is used only to operate its Discord functionality, respond to commands, and perform actions requested by users or authorized server administrators.

4. Data Storage

The Bot does not maintain a database or intentionally retain personal user information. Command input is processed to perform the requested action and is not intentionally stored by the Bot after the interaction.

Important: Discord itself may process and retain information according to Discord's own Privacy Policy and Terms. This policy applies to the Spanish Virtual League Bot and does not replace Discord's policies.

5. Data Sharing

We do not sell, rent, or intentionally share information obtained through the Bot with third parties. The Bot uses Discord's API to provide its functionality.

6. Data Security

We take reasonable measures to limit access to the Bot and its configuration. However, no online service can guarantee absolute security.

7. Children's Privacy

The Bot is a Discord application and is intended to be used in accordance with Discord's age requirements and policies. We do not intentionally collect personal information from children.

8. Data Deletion Requests

Because the Bot does not intentionally maintain a database of personal user information, there is normally no user profile data stored by the Bot to delete. If you have a privacy-related request or believe information connected to the Bot has been retained, please contact the Bot's developer through the official Spanish Virtual League Discord server.

9. Changes to This Policy

We may update this Privacy Policy if the Bot's functionality or data practices change. The "Last updated" date at the top of this page will be changed when updates are made.

10. Contact

For privacy questions or requests, contact the developer through the official Spanish Virtual League Discord server.
